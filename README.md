# Mobile App Development Lab

Flutter laboratory exercises and class activities completed during **Year 2, Term 3** at the **Cambodia Academy of Digital Technology (CADT)**.

## Technologies

* Flutter
* Dart
* Git & GitHub

## Structure

```text
lib/
├── activity1.dart
├── main.dart
├── W3/
│   ├── EX-1
│   ├── EX-2
│   ├── EX-3
│   └── EX-4
└── W4/
    ├── EX-1
    ├── EX-2
    └── EX-3
```

All weekly laboratory exercises are stored in the `lib/W<number>/` directories.

## Run the Project

```bash
flutter pub get
flutter run lib/main.dart
```

To run a specific exercise, replace the entry file accordingly.
